# Desafio 2: Domando um legado

O aluno recebe o Balcão, uma central de chamados que funciona mas foi feita às pressas e sem revisão, e instala nele o harness que o torna seguro para agentes. O enunciado está em `enunciado.md`.

- `especificacao-base.md`: contrato do Balcão e lista dos problemas plantados de propósito. Documento interno, nunca vai para o aluno.
- `balcao/`: o projeto gerado a partir da especificação. É o que o aluno recebe, extraído para um repositório próprio com `git subtree split --prefix=desafio-2-balcao/balcao`.
